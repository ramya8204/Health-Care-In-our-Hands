# Health-Care-In-our-Hands
**Health Care in Our Hands** is an Android application aimed at making healthcare services easily accessible. 
It allows users to schedule doctor appointments, order medicines, and book lab tests directly from their smartphones. 
Built with **Java** in **Android Studio**, the app focuses on a clean, user-friendly interface and a seamless experience.

## 📋 Features
- **Doctor Appointments:**  
   - Search for doctors by specialty and location.  
   - Schedule, reschedule, or cancel appointments easily.  
   - Receive notifications for upcoming appointments.  

- **Medicine Orders:**  
   - Browse a wide range of medicines.  
   - Add to cart and place orders conveniently.  
   - Track order status and delivery updates.  

- **Lab Test Bookings:**  
   - Browse available lab tests and select convenient slots.  
   - Access reports directly within the app.  
   - Notifications for test results availability.  

- **User Authentication:**  
   - Secure sign-up and login using email and password.  
   - Manage profiles and view appointment history.  

- **Responsive UI:**  
   - Clean and intuitive design for smooth navigation.  
   - Optimized for various screen sizes.  

## 🛠️ Technologies Used
- **Platform:** Android Studio  
- **Language:** Java
